# Architecture Decision Records (ADR)

Directory for recording significant architectural changes and decisions (Rule 27 & 39).

## File Naming Convention
- `ADR-[0001]-[title].md`

## Standard Structure:
```markdown
# ADR [Number]: [Title]

- **Date**: YYYY-MM-DD
- **Status**: [Proposed / Accepted / Rejected / Superseded]

## Context & Problem Statement
## Decision Drivers & Options Considered
## Decision Outcome & Rationale
## Pros and Cons / Trade-offs
## Impact Analysis
```
