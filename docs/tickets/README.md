# Implementation Tickets (`/to-tickets`)

Directory for actionable work tickets broken down from specifications.

## File Naming Convention
- `TICKETS-[feature-name].md` or `TICKET-[id]-[name].md`

## Standard Structure:
```markdown
# Ticket: [TICKET-ID] [Title]

- **Module**: `modules/[feature]`
- **Status**: [Todo / In Progress / Review / Done]
- **Dependencies**: [Ticket IDs or none]

## Description & Scope
## Implementation Checklist
- [ ] Subtask 1
- [ ] Subtask 2
## Acceptance Criteria
## Testing Requirements
- [ ] Unit Test
- [ ] Integration Test
## Definition of Done (DoD)
```
