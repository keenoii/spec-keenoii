# Requirements & Analysis (`/grill-with-docs`)

Directory for storing requirements analysis, feature summaries, confirmed business rules, ambiguities, and edge cases discovered during the `/grill-with-docs` phase.

## File Naming Convention
- `[feature-name]-requirement.md` (e.g. `auth-requirement.md`, `attendance-requirement.md`)

## Standard Format:
```markdown
# [Feature Name] Requirement Analysis

## 1. Summary
## 2. Confirmed Requirements
## 3. Ambiguities & Questions
## 4. Missing Requirements
## 5. Business Rules & Permissions
## 6. Edge Cases & Risks
## 7. Readiness
```
