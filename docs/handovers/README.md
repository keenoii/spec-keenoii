# AI Handover Logs (`AI Handover`)

Directory for persisting context across AI sessions, agents (Claude, Antigravity, Cursor, etc.), and developers (Rule 39).

## File Naming Convention
- `handover-[YYYY-MM-DD]-[topic].md`

## Standard Structure:
```markdown
# Session Handover: [Date] - [Topic]

- **Previous Agent / Author**: [Agent / Model]
- **Current Progress**:
  - [x] Completed task A
  - [ ] Pending task B
- **Active Context & Next Steps**:
- **Known Issues & Technical Debt**:
- **Key Files Modified**:
```
